# Описание библиотеки линейной алгебры

## Описание проекта

Данный проект представляет собой библиотеку линейной алгебры, реализованную на языке C++. Основным классом библиотеки является `linalg::Matrix`, предназначенный для хранения и обработки матриц произвольной размерности. Размер матрицы определяется во время выполнения программы, а все элементы хранятся непрерывном динамическом массиве.

Проект организован как отдельная библиотека, которую можно подключать к другим проектам с помощью CMake.

## Структура проекта

```
include/
    Заголовочные файлы библиотеки

source/
    Реализация класса Matrix и глобальных функций

CMakeLists.txt
README.md
```

## Класс Matrix

Класс `Matrix` инкапсулирует данные матрицы и предоставляет интерфейс для работы с ними.

Внутри объекта хранятся:

* указатель на динамический массив элементов
* количество строк
* количество столбцов
* вместимость матрицы

Для хранения элементов используется единый непрерывный массив типа `double`. Управление памятью организовано по аналогии с `std::vector`: память может резервироваться заранее, что позволяет избежать лишних перевыделений при изменении размера матрицы.

## Конструкторы

В библиотеке реализованы основные способы создания матриц:

* конструктор по умолчанию
* конструкторы с указанием размеров матрицы
* конструктор с заполнением начальным значением
* конструктор копирования
* конструктор перемещения
* создание матрицы с использованием `std::initializer_list`.

В конструкторе копирования память перевыделяется, а в перемещающем - нет.

Пример использования:

```cpp
linalg::Matrix A(3, 3);
linalg::Matrix B{{1, 2}, {3, 4}};
```

## Работа с памятью

Для изменения размера и управления памятью реализованы методы:

* `reshape()` - меняет текущий размер матрицы
* `reserve()` - резервирует память под матрицу из n элементов
* `clear()` - очищает матрицу, т.е. меняет её актуальный размер, без изменения вместимости
* `shrink_to_fit()` - перевыделяет память в соответствии с текущим размером матрицы
* `swap()` - меняет содержимое двух матриц


## Доступ к элементам

Обращение к элементам осуществляется с помощью перегруженного оператора `()`:

```cpp
matrix(i, j)
```

Для константных и неконстантных объектов реализованы разные версии оператора, что обеспечивает корректную работу с константными матрицами.

Кроме того, реализованы методы `begin()` и `end()`, позволяющие использовать матрицу в range-based циклах.

## Арифметические операции

Для класса описаны основные арифметические операторы:

* сложение и вычитание матриц
* умножение матриц
* умножение матрицы на число
* операторы сравнения

## Вычислительные методы

Библиотека содержит реализацию нескольких распространённых операций линейной алгебры:

* вычисление нормы Фробениуса
* вычисление следа
* вычисление определителя
* вычисление ранга
* прямой и обратный ход метода Гаусса
* конкатенация матриц
* транспонирование матриц
* вычисление обратной матрицы с вычислительной точностью не меньше `EPS = 1e-12`
* решение линейных систем для квадратных матриц методом Гаусса

Часть методов изменяет текущую матрицу, остальные возвращают новую матрицу как результат вычислений.

## Работа с потоками

Для удобства использования перегружены операторы ввода и вывода.

Оператор вывода форматирует матрицу в виде таблицы с выравниванием элементов по столбцам.

## Глобальные функции

Некоторые операции реализованы в виде глобальных функций, а не методов класса. К ним относятся, например:

* `concatenate()`;
* `transpose()`;
* `invert()`;
* `power()`;
* `solve()`.
* `swap()`;

Это необходтмо для корректной работы данных операторов при смене последоватекльности применения.
